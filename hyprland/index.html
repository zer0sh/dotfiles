    Hyprland Architecture

    Hyprland is organized using a strict modular approach. The primary hyprland.conf does not define keybindings or individual properties directly; it acts exclusively as an orchestrator using source = directives.

    Directory & File Structure

    ~/.config/hypr/
├── hyprland.conf         # Master entrypoint (imports sub-modules only)
├── binds.conf            # Keyboard shortcuts and mouse actions
├── monitors.conf         # Screen layouts and refresh rates (nwg-displays)
├── workspaces.conf       # Virtual desktop allocations
├── autostart.conf        # Startup services and daemons (exec-once)
├── animations.conf       # Bezier curves and window movement dynamics
├── decoration.conf       # Borders, shadows, blur, and gaps
├── miscellaneous.conf    # Keyboard repeat rate and layout behavior
├── window.conf           # Window rules & XWayland fixes (see xwayland.md)
├── hyprlock.conf         # Lock screen layout and theming
├── hypridle.conf         # Idle management and power saving
├── scripts/              # Executable shell helpers (OCR, screenshots, filters)
└── shaders/              # Custom GLSL post-processing shaders

    Master Entrypoint (hyprland.conf)

    # Monitor layout managed by nwg-displays
source = $HOME/.config/hypr/monitors.conf

source = $HOME/.config/hypr/variables.conf
source = $HOME/.config/hypr/binds.conf
source = $HOME/.config/hypr/window.conf
source = $HOME/.config/hypr/decoration.conf

# Centralized palette generated by the active theme
source = $HOME/.config/themes/current/hyprland.conf

source = $HOME/.config/hypr/animations.conf
source = $HOME/.config/hypr/miscellaneous.conf
source = $HOME/.config/hypr/autostart.conf

    Startup Services (autostart.conf)

    • Quickshell: Loads desktop widgets, top-center OSD layers & notifications, and the One UI control center.
    • Waybar: Top system status bar running alongside Quickshell widgets.
    • Polkit Agent: systemctl --user start hyprpolkitagent for GUI privilege escalation.
    • Cliphist: Text and image clipboard history daemons integrated with Quickshell clipboard drawer.
    • Wallpaper & Theme: Automatic restoration via $HOME/.config/hypr/scripts/restore-wallpaper and Matugen theming engine.
    • Desktop Environment Sync: dbus-update-activation-environment and systemctl --user import-environment for WAYLAND_DISPLAY and XDG_CURRENT_DESKTOP.
    • Battery & Charger Monitor: Real-time daemon $HOME/.config/hypr/scripts/battery-notify monitoring AC connection/disconnection and dispatching 20% / 10% low battery notifications.

    Desktop Portals & GNOME App Latency

    Applications built on GTK4 and Libadwaita (Nautilus, GNOME Calculator, Text Editor, Loupe) may experience a severe startup delay (~3.5 seconds) if portal backends are improperly prioritized.

    Cause of Delay

    xdg-desktop-portal-gnome expects GNOME Shell and Mutter services on D-Bus. When running under Hyprland, these services do not exist, causing D-Bus calls to hang until reaching their timeout. Masking the systemd service alone is insufficient because D-Bus service activation files (/usr/share/dbus-1/services/) still trigger queries.

    Resolution

    1. Purge GNOME Portal Backend: 
      sudo apt remove --purge xdg-desktop-portal-gnome
    2. Configure Preferred Portals (~/.config/xdg-desktop-portal/portals.conf): 
      [preferred]
default=hyprland;gtk
    3. Environment Activation (autostart.conf): 
      exec-once = dbus-update-activation-environment --systemd WAYLAND_DISPLAY XDG_CURRENT_DESKTOP
exec-once = systemctl --user import-environment WAYLAND_DISPLAY XDG_CURRENT_DESKTOP
