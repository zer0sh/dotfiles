# Dotfiles - Hyprland & Agent Optimized

Este repositorio contiene las configuraciones personales para un entorno de escritorio basado en Hyprland, diseñado para ser gestionado y mantenido tanto por humanos como por agentes de IA.

## Estructura
- `hypr/`: Configuraciones de Hyprland (modularizadas).
- `ai-agent/`: Metadatos e instrucciones para agentes MCP.

## Requisitos
- **OS:** Arch Linux (o derivados).
- **WM:** Hyprland.
- **Tools:** Git, MCP-compatible agent (opcional).

## Gestión por IA
Este repo incluye una carpeta `ai-agent/` con configuraciones MCP para permitir que agentes de IA ayuden en la automatización y mantenimiento de los dotfiles.
