# btop Resource Monitor

btop is a GPU/CPU/Memory/Disk/Network terminal resource monitor whose dashboard colors are regenerated from the active wallpaper by [Matugen](matugen.md).

---

## File Structure & Paths

* **Repository configuration:** `~/dotfiles/btop/btop.conf`
* **Local configuration symlink:** `~/.config/btop/btop.conf` -> `~/dotfiles/btop/btop.conf`
* **Custom themes directory:** `~/.config/btop/themes/`
* **Active dynamic theme symlink:** `~/.config/btop/themes/matugen.theme` -> `~/.config/themes/current/btop.theme`
* **Automation setup script:** `~/dotfiles/scripts/setup-btop-matugen.sh`

---

## Dynamic Matugen Integration

btop inherits the active desktop color palette generated by Matugen from the current wallpaper:

```
Wallpaper Image (.png / .jpg)
          |
          v
   [ matugen image ]
          |
          v (evaluates ~/.config/matugen/templates/btop.theme)
~/.config/themes/current/btop.theme
          |
          v (symlink)
~/.config/btop/themes/matugen.theme
          |
          v (consumed by)
btop (color_theme = "/home/zero/.config/btop/themes/matugen.theme", theme_background = True)
```

### Key Theme Settings in `btop.conf`
* **`color_theme = "/home/zero/.config/btop/themes/matugen.theme"`:** Absolute path to the theme symlink, which resolves to the freshly generated `~/.config/themes/current/btop.theme` on every wallpaper change.
* **`theme_background = True`:** btop is allowed to paint its own dashboard background. The Matugen template emits an empty `main_bg`, so no background color is forced and the terminal background from [Alacritty](../terminals/alacritty.md) stays visible. Set it to `False` to make btop always defer to the terminal background.
* **`truecolor = True`:** Enables full 24-bit RGB color depth.

## Automated Theme Deployment

To initialize or refresh the btop dynamic theme, run:

```bash
~/dotfiles/scripts/setup-btop-matugen.sh
```

Whenever wallpapers are changed via the Quickshell Control Center, `~/.config/themes/apply-matugen.sh` automatically re-renders `btop.theme` alongside all other desktop components.

---

## Key Settings & Presets

* **Update rate:** 2000ms (`update_ms = 2000`).
* **Process sorting:** Sorted by CPU usage in descending order (`proc_sorting = "cpu lazy"`, `proc_reversed = True`).
* **Presets:** Quick layout profiles configured via `presets` in `btop.conf` (switchable using keys `1` through `9`).
