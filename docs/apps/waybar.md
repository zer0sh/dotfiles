# Waybar Status Bar

Waybar serves as the primary top status bar in this desktop environment, engineered with a ChromeOS Shelf aesthetic, rounded capsule pills, and seamless IPC communication with [Quickshell](../quickshell/index.md) and the [Hyprland compositor](../hyprland/index.md).

---

## Architecture and File Map

* **Live symlink:** `~/.config/waybar` -> `~/dotfiles/waybar`
* **Configuration:** `~/.config/waybar/config.jsonc` (module layout and actions)
* **Stylesheet:** `~/.config/waybar/style.css` (visual properties and ChromeOS pill styling)
* **Dynamic Palette:** `~/.config/waybar/colors.css` (imports `~/.config/themes/current/waybar.css` generated by [Matugen](matugen.md))
* **Battery Alert Stylesheet:** `~/.config/waybar/battery-alert.css` (dynamically generated low-battery keyframe rules)
* **Helper Scripts:**
    * `~/.config/waybar/scripts/notifications`: Reads real-time notification queue state
    * `~/.config/waybar/scripts/battery-alert`: Background daemon monitoring power thresholds, dispatching notifications, and pulsing the status pill

---

## Layout and Modules

Waybar is docked at the top of the display with a height of 36 pixels and bottom corner rounding (`border-radius: 0 0 24px 24px`):

```text
+-------------------------------------------------------------------------------------------------------+
| [Launcher] [Workspaces]               [Active Window Title]             [Tray] [Notifs] [Unified System Pill] |
+-------------------------------------------------------------------------------------------------------+
```

### 1. Left Section
* **`custom/launcher`:** Circular action button styled after the ChromeOS app launcher. Clicking executes `qs ipc call launcher toggle` to display the Quickshell application drawer.
* **`hyprland/workspaces`:** Pill container with dynamic indicators. Inactive workspaces appear as muted capsule pills, while the active workspace morphs into an accented circular indicator.

### 2. Center Section
* **`hyprland/window`:** Displays the active window title with subtle opacity, keeping the central area clean and legible.

### 3. Right Section
* **`tray`:** Wayland system tray for background application icons (`icon-size: 14px`, `spacing: 8px`).
* **`custom/notifications`:** Notification bell pill connected to Quickshell's notification daemon:
    * Reads unread count from `/tmp/qs-notif-count`.
    * Receives instant wakeup via POSIX signal `SIGRTMIN+1` whenever notifications arrive or dismiss.
    * Clicking invokes `qs ipc call notifications toggle`.
* **Unified Status Pill:** Merged continuous capsule pill containing date, time, audio, network, bluetooth, and battery/power:
    * **`custom/date`:** Formatted date (`date +'%b %d'`), styled as the rounded left edge of the unified pill.
    * **`clock`:** Local time format `{:%H:%M}` with bold typography.
    * **`pulseaudio`:** Volume glyphs; click toggles Quickshell Control Center, right-click opens `pavucontrol`, and mouse wheel scrolling adjusts sink volume using `wpctl set-volume`.
    * **`network`:** Wi-Fi / Ethernet state; click opens Quickshell Control Center.
    * **`bluetooth`:** Adapter state and connection count; click opens Quickshell Control Center.
    * **`battery` / `custom/power`:** Charge percentage, charging animations, and battery warnings (laptop) or power state (desktop), styled as the rounded right edge of the unified pill.

## Integration with Quickshell and Hyprland

Waybar and Quickshell operate in synchronized coexistence:

1. **Vertical Hierarchy:**
   * Waybar occupies the top 36 pixels (`height: 36`, `layer: top`).
   * Quickshell floating toasts and OSDs reserve a `topMargin: 46` px, creating an aligned 10 px air gap directly below Waybar's rounded bottom border (see [Notifications & OSDs](../quickshell/osd-notifications.md)).
2. **IPC Interactivity:**
   * Clicking audio, network, or bluetooth indicators directly opens the One UI Control Center inside Quickshell.
   * Clicking the launcher circle opens the Quickshell app search matrix without requiring full-screen interruptions.
3. **Real-time Signal Sync (`SIGRTMIN+1`):**
   * Quickshell writes unread counts to `/tmp/qs-notif-count` and issues `pkill -RTMIN+1 waybar`, triggering immediate redraws without CPU polling overhead.

## Dynamic Palette Integration (Matugen)

Colors and translucency tokens are imported dynamically from the centralized theme store:

```css
/* ~/.config/waybar/colors.css */
@import url("/home/zero/.config/themes/current/waybar.css");
```

### Supported Color Tokens
* `@bg`: Canvas backdrop with 80% alpha opacity (`alpha(@bg, 0.80)`).
* `@text`: Primary typography and icon color.
* `@accent`: Active workspace indicator and highlight borders.
* `@warning`: Battery low threshold (<= 30%).
* `@critical`: Battery critical threshold (<= 10%).
* `@charging`: Battery active power supply state.

### Reloading Waybar Stylesheet Live
To reload Waybar styling without restarting the process:

```bash
pkill -SIGUSR2 waybar
```

## Battery Alert System and Dynamic Pill Animation

A dedicated background daemon (`~/.config/waybar/scripts/battery-alert`) provides proactive multi-tier power monitoring and real-time visual status bar feedback.

### 1. Alert Thresholds and Desktop Notifications

The daemon monitors battery capacity and AC power supply state via Linux sysfs (`/sys/class/power_supply/`), dispatching desktop notifications through `notify-send`:

| Threshold | Event | Urgency | Icon | Description |
| :--- | :--- | :--- | :--- | :--- |
| **30%** | Warning | `normal` | `battery-caution` | Advisory alert prompting the user to connect power soon |
| **10%** | Critical | `critical` | `battery-low` | High-urgency alert warning against impending auto-suspend |
| **5%** | Ultimatum | `critical` | `battery-empty` | Severe alert advising that system shutdown is imminent |
| **AC Connect** | Charging | `normal` | `battery-full-charging` | Notification confirming charger connection and current level |

### 2. Status Pill Red Blinking Effect

Whenever the battery discharges to 30% or below, the daemon dynamically writes keyframe animation rules into `~/.config/waybar/battery-alert.css` and signals Waybar via `pkill -SIGUSR2 waybar`:

* **Target Modules:** The entire unified right pill (`#custom-date`, `#clock`, `#pulseaudio`, `#network`, `#bluetooth`, `#battery`, and variants) pulses with red accents in perfect synchronization.
* **Progressive Flash Frequency:**
    * **Warning (11% - 30%):** Gentle pulse at 1.0s interval (`rgba(230, 40, 40, 0.40)`).
    * **Critical (6% - 10%):** Faster pulse at 0.6s interval (`rgba(230, 30, 30, 0.55)`).
    * **Ultimatum (<= 5%):** Urgent rapid flash at 0.35s interval (`rgba(240, 15, 15, 0.70)`).
* **Automatic Reset:** As soon as AC power is connected or the battery charges above 30%, the daemon empties the stylesheet and resets the status pill back to standard styling.

### 3. Process Lifecycle and Guarding

* **Single-instance locking:** Uses `flock` on `/tmp/waybar-battery-alert.lock` to prevent redundant daemon processes.
* **Session autostart:** Registered in `~/.config/hypr/autostart.conf` (`exec-once = $HOME/.config/waybar/scripts/battery-alert`).
* **Clean exit traps:** Ensures any `SIGINT` or `SIGTERM` signal flushes the CSS to its default idle state before termination.
