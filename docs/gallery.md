# Visual Showcase & Gallery

A visual catalog demonstrating the aesthetic cohesion, Material Design 3 theming, window tiling, and utility suite configured across zer0sh's dotfiles environment.

---

## 1. Desktop & Tiling Overview

A full overview of the Hyprland tiling workspace featuring Alacritty, Fastfetch telemetry, Lazygit for interactive version control, desktop clock widget, and the top-centered Waybar pill status bar.

![Desktop Overview](assets/images/showcase/desktop-overview.png)

![Desktop Overview (variant)](assets/images/showcase/desktop-02.png)

### Key Elements Highlighted:
* **Tiling Composition:** Active window borders automatically accented with colors generated by Matugen from the desktop wallpaper.
* **Status Pill (Waybar):** Centralized navigation pill displaying workspaces, active window title, and system tray.
* **Terminal Diagnostics:** Fastfetch providing hardware telemetry, shell load timings, and system specs.
* **Git Workflow:** Lazygit running natively inside Alacritty using BlexMono Nerd Font typography.

## 2. Dynamic Lock Screen (Hyprlock)

Frosted glass lockscreen engineered in Material Design 3 dual-panel layout, featuring a stacked monumental clock, dynamic wallpaper blur, and biometric-styled authentication profile.

![Hyprlock Screen](assets/images/hyprland/hyprlock.png)

### Key Features:
* **Google Sans Flex Rounded:** Native Google Pixel typography applied to the massive 172 pt stacked hours and minutes.
* **Monumental Clock Overlap:** Hours in accent color subtly layered over the minutes for depth.
* **Adaptive Weather & Custom Location:** Integrates live temperature and custom display labels ("La Ciudad del Condor").
* **Material Transitions:** 500ms `fadeIn` and `fadeOut` animations backed by `md3_decel` and `md3_accel` cubic beziers.
* **Heavy Asterisk Feedback:** Password input rendered with stylized `✱` glyphs.

## 3. GNOME & GTK Applications Suite

Dynamic Material You theming applied universally to modern (GTK 4 / Libadwaita) and classic (GTK 3) applications.

![GTK Applications Suite](assets/images/apps/gtk-suite.png)

### Applications Featured:
* **GNOME Calendar (`gnome-calendar`):** Monthly agenda layout adopting current surface and accent color schemes.
* **Nautilus (`nautilus`):** GNOME Files manager adhering to system dark mode and custom sidebar tokens.
* **File Roller (`file-roller`):** Classic archive manager rendered with matching window and header bar styling.
* **GNOME Clocks (`gnome-clocks`):** World clock and stopwatch utilities running under unified dark palette.
* **nwg-displays (`nwg-displays`):** Wayland monitor layout and resolution configuration tool.

## 3. Modular Status Bar (Waybar)

ChromeOS Shelf-inspired top status bar engineered with rounded capsule pills, dynamic workspace morphing, and a unified system indicator pill.

![Waybar Status Bar](assets/images/apps/waybar.png)

### Key Features:
* **Launcher Button:** Invokes the Quickshell application drawer and wallpaper switcher via IPC.
* **Workspaces:** Active workspace dynamically expands into an accented circular indicator.
* **Unified Status Capsule:** Blends date, time, audio volume, network, bluetooth, and battery monitoring into a single continuous pill.

## 4. Application Launcher (Wofi)

Dynamic Material Design 3 application launcher featuring centralized fuzzy search, desktop application indexing, and live color styling generated by Matugen.

![Wofi Application Launcher](assets/images/apps/wofi-launcher.png)

### Key Features:
* **Fuzzy Matching:** Instant filtering across installed applications and utilities.

## 5. Quickshell Desktop Layer & Selectors Suite

### Desktop Gadgets Selector

The Material Design 3 interactive selector opened via `gadgetpicker` (`/gadgets` or `SUPER + G`), displaying a horizontal carousel of available desktop widgets (Desk Clock, Calendar, Weather Forecast, Hardware Pulse, Ambient Scratchpad, and Daily Spark) with real-time toggle feedback.

![Quickshell Desktop Gadgets Selector](assets/images/quickshell/launcher-gadgets.png)

### Floating Launcher & Wallpaper Carousel

The Material Design 3 launcher opened in wallpaper mode (`/wallpaper` or `SUPER + W`), rendering a horizontal carousel of 16:9 previews with the active wallpaper highlighted by an accent glow.

![Quickshell Wallpaper Carousel](assets/images/quickshell/launcher-wallpapers.png)

### Screen Shaders & CRT Effects Carousel

The shader selector (`/shader` or `SUPER + B`), providing live switching between CRT Trinitron, Retro CRT, Sepia, Black & White, Film Noir, Vintage, and Vivid filters.

![Quickshell Screen Shaders Selector](assets/images/quickshell/launcher-shaders.png)

### Dynamic Material You Theme Carousel

Interactive theme palette selector (`/theme`), allowing instant switching between generated Matugen wallpaper palettes and curated presets.

![Quickshell Themes Carousel](assets/images/quickshell/launcher-themes.png)

### Floating Music Player (Dynamic Island)

Integrated non-modal media controller (`/music` or `SUPER + M`), providing active track telemetry, cover display, scrub progress bar, and MPRIS playback controls.

![Quickshell Music Player](assets/images/quickshell/launcher-music.png)

### Dynamic Command Drawer & Actions

The command mode launcher (`/`), presenting instant system actions, hibernation, restart, power controls, and navigation shortcuts with fuzzy search.

![Quickshell Actions Launcher](assets/images/quickshell/launcher-actions.png)

### Workspace Overview (2x5 Grid Exposé)

Full-screen hardware-accelerated overview modal (`SUPER + Tab`), mapping all 10 Hyprland workspaces in a responsive 2×5 layout with live window thumbnails and spatial navigation.

![Quickshell Workspace Overview](assets/images/quickshell/overview.png)

### Clipboard History Drawer

Wayland-native clipboard manager (`SUPER + V`) anchored smoothly below the status bar, supporting fuzzy search, text and image buffer previews powered by `cliphist`.

![Quickshell Clipboard Drawer](assets/images/quickshell/clipboard.png)

### Keyboard Shortcuts Cheatsheet

Modal shortcuts reference (`F1`) displaying all active Hyprland keybindings dynamically parsed from `binds.conf` with Material chip keycaps.

![Quickshell Shortcuts Overlay](assets/images/quickshell/shortcuts-overlay.png)

### Control Center & Quick Toggles

Sliding system control center featuring brightness and volume sliders, power profiles, Wi-Fi, Bluetooth, Do Not Disturb, and hardware monitors.

![Quickshell Control Center](assets/images/quickshell/control-center.png)

### Session Power Menu

Full-screen frosted power menu (`CTRL + ALT + Delete`) providing lock, suspend, reboot, and power-off actions.

![Quickshell Power Menu](assets/images/quickshell/powermenu.png)

### Notification Toasts & OSD Cards

Floating notification toasts stacking downwards from the top-center of the display, each with its application badge, title, and body text.

![Notification Toasts](assets/images/quickshell/notifications-toast.png)

Translucent volume and brightness OSD cards rendered with the same Material You surface tokens, auto-dismissing after two seconds of inactivity.

![Volume OSD](assets/images/quickshell/osd-volume.png)

![Brightness OSD](assets/images/quickshell/osd-brightness.png)

### Key Features:
* **Wallpaper Carousel:** Fuzzy-filtered wallpaper browser with cached thumbnails, keyboard navigation, and apply-on-enter behaviour.
* **Toast Queue:** New notifications are prepended into the top slot and push older cards downwards through a `move` transition (maximum of four concurrent toasts).
* **OSD Placement:** 360 x 56 px cards anchored 46 px below the 36 px Waybar strip, so status indicators remain visible while the card animates in.
* **Palette Sync:** Lazily instantiated Wayland layershell surfaces styled exclusively from Matugen `surface_container`, `outline`, and `on_surface` tokens.
