    Vim Configuration

    Vim serves as the modal terminal text editor in this environment, configured with modern UI ergonomics, dynamic Material Design 3 theming generated by Matugen (with SynthWave '84 as fallback), vim-airline status bar theming, NERDTree file explorer, and full system clipboard synchronization under Debian and Wayland.

    File Structure & Paths

    • Repository configuration: ~/dotfiles/vim/vimrc
    • Vim directory & plugins: ~/dotfiles/vim/dot-vim
    • Active user symlinks:
    • ~/.vimrc -> ~/dotfiles/vim/vimrc
    • ~/.vim -> ~/dotfiles/vim/dot-vim

    System Dependencies (Debian / Wayland)

    To enable seamless copy/paste integration with Wayland and manage plugins, the following packages are required on Debian:

    sudo apt install vim-gtk3 wl-clipboard
    • vim-gtk3: Replaces the default vim.basic binary with a version compiled with +clipboard and +xterm_clipboard. This activates set clipboard=unnamedplus in terminal sessions without launching a graphical window.
    • wl-clipboard: Provides wl-copy and wl-paste command-line tools for native clipboard buffer management in Wayland / Hyprland.
    • git & curl: Required by the vim-plug package manager to fetch and update plugin repositories.

    Plugin Architecture (vim-plug)

    Plugins are managed via junegunn/vim-plug stored in ~/.vim/autoload/plug.vim and cloned into ~/.vim/plugged/:

    • preservim/nerdtree: Tree-style directory viewer and file explorer.
    • artanikin/vim-synthwave84: Neon synthwave color scheme kept as an automatic fallback when no Matugen palette has been generated yet.
    • vim-airline/vim-airline: Lightweight, customizable bottom statusline.
    • vim-airline/vim-airline-themes: Theme collection for vim-airline (configured to matugen, which mirrors the active colorscheme).

    Dynamic Matugen Theme

    The active colorscheme follows the desktop palette generated by Matugen from the current wallpaper:

    • Colorscheme loader: ~/.vim/colors/matugen.vim sources the generated palette from ~/.config/themes/current/matugen.vim and silently falls back to synthwave84 if the file does not exist yet.
    • Airline loader: ~/.vim/autoload/airline/themes/matugen.vim exposes the same palette to vim-airline (normal, insert, visual, replace and inactive section colors). It only sources the generated file when the palette variable is not defined, so highlight groups are never cleared twice on startup.
    • Generation source: ~/dotfiles/matugen/templates/matugen.vim, wired through the [templates.vim] entry in ~/.config/matugen/config.toml.
    • Airline palette guard: the generated file builds the airline palette only when g:loaded_airline is set, because airline#themes#generate_color_map is an autoload function that cannot be detected with exists() before it has been loaded.

    # Regenerate every palette (including matugen.vim) from the active wallpaper
bash ~/dotfiles/themes/apply-matugen.sh

    Already running instances pick up the new palette with :colorscheme matugen, which reloads both the highlight groups and the airline palette in place.

    Key Settings & Ergonomics

    Usability & Editing

    • Indentation: 2-space soft tabs (tabstop=2, shiftwidth=2, expandtab).
    • Line numbers: Absolute line numbering enabled (number).
    • Search: Incremental and case-smart searching (incsearch, hlsearch, ignorecase, smartcase).
    • True Color: 24-bit RGB colors enabled when supported by the terminal emulator (termguicolors).
    • Mouse: Full pointer support for scrolling and cursor positioning across all modes (mouse=a).
    • Clipboard: Centralized synchronization with the system clipboard (clipboard=unnamedplus).
