    Alacritty Configuration

    Alacritty serves as the secondary terminal emulator in this environment, running the Zsh Shell with instant live configuration reloading and tight integration with the Matugen Dynamic Theming Engine. Kitty is the default terminal bound to SUPER + Return, and both terminals share the same typography, padding, opacity and palette.

    File Locations

    • Repository source: ~/dotfiles/alacritty/alacritty.toml
    • Target symlink: ~/.config/alacritty/alacritty.toml
    • Imported color palette: ~/.config/themes/current/alacritty.toml

    Dynamic Theme Integration (Matugen)

    Alacritty delegates color palette definitions to an externally managed file generated by Matugen:

    [general]
import = ["/home/zero/.config/themes/current/alacritty.toml"]
live_config_reload = true

    Live Update Workflow

    1. Matugen processes the current desktop wallpaper or the manual theme selected via the Quickshell Control Center.
    2. It evaluates the template located at ~/.config/matugen/templates/alacritty.toml against the generated color roles.
    3. The resulting palette is written to ~/.config/themes/current/alacritty.toml.
    4. Because live_config_reload = true is enabled, all active Alacritty windows immediately update their colors without restarting or interrupting active shell sessions.

    Visual Settings & Typography

    [window]
opacity = 0.92
padding = { x = 15, y = 15 }

[cursor]
style = { shape = "Underline", blinking = "On" }

[font]
normal = { family = "BlexMono Nerd Font", style = "Bold" }
bold   = { family = "BlexMono Nerd Font", style = "Bold" }
italic = { family = "BlexMono Nerd Font", style = "Bold Italic" }
    • Padding: Configured to 15 x 15 px to ensure clean breathing room between terminal text and Hyprland window borders.
    • Opacity: 0.92, providing subtle background transparency that blends with Hyprland dual-layer blur while maintaining high contrast and readability.
    • Font: BlexMono Nerd Font (Bold weight) for crisp glyph rendering and comprehensive icon support, matching Wofi Launcher.

    Associated Keybindings

    • No default keybinding: SUPER + Return launches the default terminal (Kitty Terminal, see the Hyprland Keybindings Catalog).
    • Launch Alacritty from the Wofi Application Launcher or from scripts such as hypr/scripts/sudo-launcher.
